# 🤖 Multi-Agent Procurement Assistant

An Agentic AI system that automates web research, product comparison, and generates professional HTML reports.

## 🚀 Features
- **Web Research:** Uses Tavily AI to search for real-time product data.
- **Analysis:** Compares prices, specs, and features.
- **Reporting:** Generates a clean HTML report.

## 🛠️ Tech Stack
- **Backend:** FastAPI, Python
- **AI Framework:** LangChain
- **LLM:** Groq (Llama 3 / GPT-OSS)
- **Search:** Tavily AI
